# Clarionet

Clarionet is a minimalist online radio player for Linux. The goal is simple: a fast, readable interface and a fully local experience with no accounts or external services.

## What it does

- Plays radio streams via mpv (m3u8, mp3, etc.)
- Import stations manually or through Radio‑Browser
- Presets 1–6 with long‑press to save
- LED‑style station and metadata display
- System volume control

## Philosophy

Clarionet focuses on clarity and restraint: fewer visible elements, direct actions, and an interface inspired by 1980s car radios. Data stays local in `~/.config/clarionet/`.

## Install

```bash
./install.sh
```

Launch:

```bash
./clarionet
```

## Shortcuts

- Space: play/pause
- S: stop
- Left/Right: volume −/+
- Up/Down: previous/next station

Work in progress. UX feedback and preset ideas are welcome.
